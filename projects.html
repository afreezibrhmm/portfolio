AI Python Tutor is an interactive educational platform designed to help students master Python through real-time code evaluation and AI-generated feedback. MedAI Diagnostics

MedAI Diagnostics is an advanced medical diagnostics dashboard for predictive breast cancer detection. It deploys an ensemble of 4 AI architectures: Deep Neural Network (MLP), XGBoost, LightGBM, and Random Forest, complete with a FastAPI inference backend and real-time clinical probability charts.

Secure WebCam

Secure WebCam is a modern computer vision and encrypted video streaming application. It provides real-time WebRTC media connectivity, computer vision frame processing, and AES-256 secure channel telemetry with a high-performance React front end.
